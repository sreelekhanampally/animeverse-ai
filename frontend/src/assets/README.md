# Assets

Place static images, illustrations, and SVGs here. They will be bundled by Vite when imported from JS/JSX.

Recommended structure:
- `src/assets/images/`  -  raster imagery
- `src/assets/icons/`  -  custom SVG icons (prefer `lucide-react` for standard icons)
- `src/assets/brand/`  -  logo variants and marketing artwork
